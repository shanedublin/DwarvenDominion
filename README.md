# Dwarven Dominion

This game as a resource collection game with elements of base building combat and trade.  The objective is to acquire 20 gems! You do this through building, combat and exploration!

This game is completely 3d printable and all the files can be found [here](./3dPrintFiles)

This game supports up to 6 players and takes 30 - 90 mins to complete

The game contains many small pieces So I would advise against letting children play who can choke on small objects.
